# Diagrams Index

This directory stores public visual assets that can be referenced by other Full Spectrum Lab repositories.

## Why diagrams live here

The diagrams are shared assets.

They should not be duplicated across protocol, engine, and enterprise repositories unless there is a very specific reason.

This repository keeps:

- stable file names
- clean public URLs
- cross-repository references
- a single place to manage asset ownership

## Naming rule

Diagram file names should be:

- lowercase
- English
- hyphen-separated
- stable enough for long-term README references

Chinese titles should stay in README captions or wiki pages, not in file names.
