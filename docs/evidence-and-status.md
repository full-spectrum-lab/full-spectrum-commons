# Evidence and Project Status

This page separates implemented evidence from research hypotheses and future plans.

## Reproducible engineering evidence

| Evidence | Current public status | Verify |
|---|---|---|
| Engine stable baseline | `v1.0.0`, local-first contract | [release boundary](https://github.com/full-spectrum-lab/full-spectrum-engine#current-release-boundary) |
| Engine regression suite | 141 tests on the v1.0 release baseline | [test status](https://github.com/full-spectrum-lab/full-spectrum-engine#test-status) |
| Governance-chain CLI | Generates and validates the ecommerce protocol object chain | [quick run](https://github.com/full-spectrum-lab/full-spectrum-engine#governance-chain-cli-ten-minute-runnable) |

| Enterprise cases | Synthetic or desensitized governance cases | [cases](https://github.com/full-spectrum-lab/full-spectrum-enterprise-governance/tree/main/cases) |

## What this evidence supports

- the public examples are reproducible;
- selected objects conform to the published schemas;
- the engine can run locally and preserve deterministic audit artifacts;
- the repository split and adoption path are documented.

## What it does not support

- production validation for a named enterprise;
- regulatory approval or compliance certification;
- proof that the research models predict real civilizations or organizations;
- completion of a cross-organization protocol network;
- authority to execute refunds, penalties, bans, or legal decisions.

## Research evidence levels

| Level | Meaning |
|---|---|
| Implemented | Code or schema exists and has reproducible tests. |
| Working paper | A public research argument that has not been peer reviewed. |
| Research hypothesis | A candidate model requiring citation, mathematical, or empirical validation. |
| Historical archive | Material retained for provenance, not a current specification or claim. |

See the [Research Index](../research/README.md) for the current working-paper policy.
