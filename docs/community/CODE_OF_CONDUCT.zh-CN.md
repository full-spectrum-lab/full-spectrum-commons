# Full Spectrum 公共社区行为准则

创建时间：2026-08-24 22:13（北京时间，UTC+8）

最后更新时间：2026-08-24 22:13（北京时间，UTC+8）

状态：`PUBLIC_COMMUNITY_DRAFT / OWNER_REVIEW_REQUIRED`

社区成员应：

- 尊重不同背景、经验和意见；
- 用事实、代码、测试和来源支持判断；
- 允许别人指出错误、未知项和过度主张；
- 不把社区讨论变成个人崇拜、商业胁迫或政治动员；
- 不公开他人隐私、凭据、客户资料或内部对话；
- 对 AI 生成内容进行人工核验，不伪造贡献和测试结果。

不接受以下行为：

- 骚扰、威胁、歧视或恶意跟踪；
- 伪造证据、测试、部署或客户采用；
- 将社区角色用于未经授权的商业、政治或安全操作；
- 绕过权限访问企业 Observer Service 或私有知识；
- 故意提交恶意代码、凭据或隐蔽遥测。

报告渠道使用仓库 Issue、Security Advisory 或维护者指定的安全邮箱。涉及隐私和安全的报告不得公开粘贴敏感内容。
