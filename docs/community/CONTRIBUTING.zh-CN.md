# Full Spectrum 公共社区贡献指南

创建时间：2026-08-24 22:13（北京时间，UTC+8）

最后更新时间：2026-08-24 22:13（北京时间，UTC+8）

状态：`PUBLIC_COMMUNITY_DRAFT / OWNER_REVIEW_REQUIRED`

## 1. 欢迎的贡献

- 文档、翻译、架构图和导航；
- Schema、测试、Golden CASE 和可复现脚本；
- Knowledge Governance 来源核验和版本整理；
- Skill 平台适配、部署、诊断和安全报告；
- 企业案例，但必须脱敏并获得公开授权；
- 对过度主张、断链、版本漂移和证据缺失的 Issue。

## 2. 提交前要求

- 说明修改目标和影响范围；
- 不把规划写成已实现；
- 不提交个人路径、凭据、客户数据或未授权材料；
- 新知识来源写明来源、版本、适用范围和许可证；
- 代码变更提供测试或说明无法测试的原因；
- 保持与仓库现有许可证和命名规则一致。

## 3. 贡献归属

提交 PR 不自动授予贡献者对 Full Spectrum 服务、知识库或企业数据的管理权限。贡献内容的许可证和版权归属按目标仓库许可证、贡献声明和单独协议执行。

## 4. 评审顺序

```text
范围确认 → 事实核验 → 安全/隐私扫描 → 技术评审 → 独立复核 → 合并
```

高风险权限、公共知识发布和服务端变更需要额外的 Owner 或 Steward 审批。
