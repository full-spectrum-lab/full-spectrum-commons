## 1. 角色定义

Steward（公共网络维护者）是社区授予的有限维护角色，负责公共开源资产、公共服务或节点协作的具体范围。Steward 不等于公司法定代表人、客户数据控制者或所有网络的超级管理员。

## 2. 贡献路径

```text
访客 → 社区成员 → 贡献者 → 评审维护者 → Steward 候选 → Steward
```

评价贡献的维度包括：

- 代码和测试质量；
- 文档和知识来源核验；
- 安全响应和问题处理；
- 独立复核能力；
- 长期维护记录；
- 对边界和隐私的遵守。

不以粉丝数量、发言次数或个人关系作为唯一依据。

## 3. Steward 权限

权限必须按范围授予，例如：

- 仓库合并权限；
- 公共 Pack 发布复核；
- 服务运行诊断；
- 社区议题主持；
- 版本和撤销公告发布。

Steward 不得：

- 读取企业私有知识或客户数据；
- 使用公共权限访问企业内部 Observer；
- 修改历史 Evidence、Audit 或 Replay；
- 单人发布高风险版本或轮换全部生产凭据；
- 将社区角色当作法律、商业或监管授权。

## 4. 任期与撤销

- Steward 角色应有任期或定期复审；
- 权限可因长期不活跃、利益冲突、安全违规或证据不诚实而暂停；
- 撤销操作必须有记录和复核；
- 离任时完成密钥、账号和仓库权限移交。

## 5. 双人和透明原则

公共服务、固定知识发布、撤销和安全响应尽量采用双人复核。社区定期公开角色、范围、变更和重大事件摘要，但不公开私有数据和安全细节。
