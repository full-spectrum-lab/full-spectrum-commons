## 1. 使命

Full Spectrum 公共社区致力于把 AI、知识、观察、证据和责任边界建设成可理解、可复核、可复用的开源工程资产。

社区不承诺替任何组织作最终经营、法律或公共治理决定。社区的基本立场是：机器输出必须能够回指身份、版本、来源、证据和责任边界。

## 2. 公共社区与产品仓库的关系

| 层 | 主要职责 |
|---|---|
| `full-spectrum-commons` | 公共导航、研究、社区规则和跨仓库协调 |
| `full-spectrum-protocol` | 协议、Schema、兼容性和边界合同 |
| `full-spectrum-engine` | 可复算治理计算和运行时 |
| `full-spectrum-observer` | 观察、Evidence、Audit、Replay 和人工复核 |
| `full-spectrum-knowledge-governance` | 知识身份、版本、来源、生命周期、冲突和回放 |
| `full-spectrum-enterprise-governance` | 企业案例、适配器、部署和实践材料 |

## 3. 社区原则

1. 证据优先：实现、测试、固定提交和 Release 高于宣传文字。
2. 边界透明：明确区分已实现、已发布、已设计、规划和未评估。
3. 人工责任：Skill、Engine 和 Observer 不替代最终责任人。
4. 最小权限：客户端不能自行授予权限或组合不同组织的上下文。
5. 可退出：知识、数据、服务和社区角色都应具备撤销和退出路径。
6. 长期维护：优先建设可维护的合同、测试和文档，而不是追逐概念数量。

## 4. 当前阶段

当前处于公共社区建设和 Skill 公共试水准备阶段。公共分析网点、企业 Observer Service 网络和 Steward 网络均属于分阶段目标，不能写成已经运行的事实。
