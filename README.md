# Full Spectrum Commons

Shared assets, indexes, diagrams, glossary materials, and cross-repository navigation for the Full Spectrum Lab GitHub organization.

This repository is the public commons layer of the ecosystem. It is not the protocol source of truth, not the runnable engine, and not the enterprise application package.

## Role in the ecosystem

Think of the GitHub organization as four layers:

- `full-spectrum-protocol` defines the protocol language, RFCs, schemas, and compatibility rules.
- `full-spectrum-engine` turns protocol ideas into a local-first runnable governance engine.
- `full-spectrum-enterprise-governance` carries business-facing cases, governance packages, and deployment-oriented documentation.
- `full-spectrum-commons` keeps the shared map: diagrams, indexes, terminology, cross-repo entry paths, and public-facing coordination assets.

## What belongs here

- shared diagrams and visual assets
- project maps and repository maps
- glossary and terminology references
- public-facing orientation materials
- cross-repository indexes
- reusable templates that are not specific to only one repository

## What does not belong here

- normative protocol definitions that should live in `full-spectrum-protocol`
- runnable code that should live in `full-spectrum-engine`
- enterprise-specific governance packages that should live in `full-spectrum-enterprise-governance`
- private customer data, private tokens, or internal-only materials

## Recommended reading path

If you are new to Full Spectrum:

1. Start with the diagrams in [`diagrams/README.md`](./diagrams/README.md)
2. Read [`ECOSYSTEM.md`](./ECOSYSTEM.md) to understand how the repositories fit together
3. Go to `full-spectrum-protocol` if you need definitions and schemas
4. Go to `full-spectrum-engine` if you need runnable examples
5. Go to `full-spectrum-enterprise-governance` if you need business-facing governance cases

## Public boundary

This repository is for orientation and shared assets.

It does not claim:

- regulatory approval
- production readiness for all repositories
- legal authority over external systems
- that every idea shown in a diagram is already fully implemented
