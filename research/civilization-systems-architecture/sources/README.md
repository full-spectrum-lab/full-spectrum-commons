# Sources and Review Records

本目录登记研究系列使用的母稿、公开工程入口和独立阅读反馈。登记本身不等于历史来源已经完成学术核验。

```ini
SOURCE_REGISTER = IN_PROGRESS
FORMAL_BIBLIOGRAPHY = NOT_COMPLETED
HUMAN_PEER_REVIEW = NOT_COMPLETED
```

每条来源应记录标题、路径或 URL、版本/提交、访问时间、材料类型、可支持的事实范围、争议和不支持的推论。
