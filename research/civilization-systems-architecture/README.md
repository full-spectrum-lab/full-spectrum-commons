# Civilization Systems Architecture

Status: `RESEARCH_SERIES / NON_NORMATIVE / IN_REVIEW / NOT_IMPLEMENTED`

This Chinese-language research series studies a bounded question: how can a long-running system change its institutions, knowledge, participants, and interpretations without losing every trace of identity, memory, responsibility, and meaning?

The series uses Chinese civilization as an initial case, not as proof of civilizational superiority and not as a software specification. Historical observations may generate hypotheses. They become engineering facts only after separate design, implementation, testing, and runtime evidence.

## Evidence labels

| Label | Meaning |
|---|---|
| `OBSERVED` | A sourced observation, still subject to source quality and dispute. |
| `INTERPRETATION` | An explanation offered by the researcher. |
| `HYPOTHESIS` | A proposition requiring comparison, counterexamples, and review. |
| `PROPOSED` | A non-normative engineering implication. |
| `IMPLEMENTED` | Code or schema exists. This series does not grant this label. |
| `RUNTIME_VERIFIED` | Runtime evidence exists. This series does not grant this label. |

## Boundary

```text
Historical observation
  -> interpretation
  -> hypothesis
  -> counterexample and comparison
  -> design proposal
  -> implementation
  -> test and runtime evidence
```

No document here overrides the Full Spectrum Protocol, Engine, Observer, Knowledge Governance, repository Releases, or their evidence.
