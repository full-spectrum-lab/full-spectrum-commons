# 反例、风险与不可兼容边界

文档编号：`FSP-CIV-ARCH-06`  
状态：`RISK_AND_COUNTEREXAMPLE_NOTE / NON_NORMATIVE / IN_REVIEW`

## 1. 连续性不是善

长期存在的系统可能保存语言、知识和协作能力，也可能保存压迫、偏见、等级和错误规则。连续性只有与适应、审计、纠偏和主体责任结合，才可能成为值得追求的系统性质。

## 2. “兼容所有差异”的边界

兼容不能被解释为所有行为都获准。破坏他人主体性、消灭共同运行条件、伪造证据或绕过授权的行为，可能触及不可兼容边界。困难在于：边界由谁提出、依据什么证据、谁有申诉权、是否可以复核。

## 3. 主要风险

- **文化本质主义**：把复杂历史压缩成一个永恒性格；
- **文明优越论**：从连续性推导道德或技术优越；
- **类比越界**：把历史对象直接等同软件组件；
- **权威洗白**：用传统或 AI 输出掩盖责任主体；
- **旧偏见自动继承**：把历史连续误当正确；
- **证据垄断**：只有中心记录可以定义过去；
- **形式化傲慢**：假定所有价值冲突都可由算法求解。

## 4. 必须寻找的反例

后续研究必须寻找：连续但高度僵化的系统、断裂后重新获得活力的系统、记忆丰富却无法纠错的系统、差异丰富却缺乏共同运行条件的系统，以及稳定与自由之间出现不同组合的案例。
